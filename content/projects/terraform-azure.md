## Goal

Model Azure infrastructure as reusable, reviewed and understandable code rather than a series of manual console changes.

## Areas of focus

- Terraform module boundaries and inputs
- Identity, networking and environment separation
- Remote state and safe change workflows
- Plan-driven review before provisioning

## Outcome

An approach that makes infrastructure changes more predictable, traceable and easier to reproduce across environments.
